# "Maya" Voice Assistant

**Role:** AI Engineer | **Stack:** Whisper, LLM, TTS

---

A low-latency conversational engine focused on natural, human-like interaction.

- **Pipeline:** VAD (Voice Activity Detection) → STT (Whisper) → LLM → TTS.
- **Optimization:** Minimized Time-to-First-Byte (TTFB) to <500ms for realistic conversation flow.
- **Goal:** Zero-latency interruptibility (User can interrupt the AI while it is speaking).
