    Maya — Real-Time Voice AI (CSM-1B Pipeline)

    Stack: CSM-1B · Llama 3.2 3B Instruct · faster-whisper large-v3-turbo · Silero VAD · FastAPI · WebSocket Hardware: Single GPU (A10G / RTX 4090 / A100, 16 GB+ VRAM) Status: Self-Hosted · Production-Ready

    GitHub → HuggingFace (CSM-1B Conversational) →

    Overview

    A fully self-hosted voice agent — not a wrapper around an API, not a chatbot with a TTS bolted on. The whole pipeline runs locally on a single GPU machine: VAD, STT, LLM, and CSM-1B streaming TTS, with audio humanization on top. ~780 ms to first audio (direct), ~1.3 s through a free ngrok tunnel.

    Feature Maya Typical voice bot
    End-to-end latency 1.3 s to first audio 3–8 s
    TTS model CSM-1B (Sesame) with frame-level streaming Cloud API
    Audio humanization Jitter + shimmer + breath synthesis None
    TTS context 8-turn audio + text context Text only
    Barge-in Real-time interruption handling Wait-for-response
    Infrastructure Self-hosted, single GPU Cloud API dependencies

    Custom CSM-1B Fine-Tune

    Released as Tachyeon/csm-1b-conversational-finetuned.
    Method Decoder-only fine-tune (decoder.pt + audio_head.pt + projection.pt)
    Base model sesame/csm-1b (1 B params, ~1 M hours of conversational audio)
    Dataset Expresso, female speaker ex04
    Training steps 5000, best checkpoint by validation loss
    Hardware NVIDIA A10G 24 GB

    The backbone is frozen — full fine-tuning risks catastrophic forgetting of the model's conversational priors. Targeting only the decoder + audio head + projection adapts voice characteristics while preserving the natural prosody CSM-1B was trained for.

    Key Engineering Details

    True streaming TTS

    Audio is generated frame-by-frame via StreamingGenerator, not chunked from a pre-generated buffer. First audio arrives after just 4 frames (~320 ms).

    Conversation context for prosody

    Up to 8 previous turns — both text and audio — are passed to CSM. If Maya was cheerful in the last turn, the next utterance maintains that energy. This is qualitatively different from text-only context.

    Dual-temperature decoding

    • temperature=1.0 for the backbone — prosodic diversity
    • depth_decoder_temperature=0.7 for the depth decoder — acoustic stability

    The split is critical: high backbone temperature gives expressive intonation; low depth temperature prevents artifacts.

    Audio humanization

    Raw TTS lacks the micro-features of human speech. The humanizer adds them in <2 ms/chunk on CPU:

    • Jitter — ~0.5 % fundamental-frequency perturbation (matches natural vocal cord behavior)
    • Shimmer — 1–3 % amplitude perturbation
    • Breath synthesis — bandpass-filtered noise (200–2000 Hz) with natural ASR envelope, inserted at phrase boundaries
    • Warmth filter — subtle low-shelf boost for body without muddiness

    Barge-in & echo handling

    1. VAD runs continuously — even while Maya is speaking
    2. If the user starts speaking, the TTS stream is cancelled and the pipeline resets to listen mode
    3. After Maya stops, a 150 ms echo cooldown prevents the mic from picking up Maya's own output (industry standard is 600 ms; this is shorter because audio normalization eliminates most echo energy)

    Whisper hallucination filtering

    Conservative allowlist approach: only exact matches of known hallucination phrases (e.g. "Thanks for watching", "Please subscribe") are rejected. Avoids both false positives (filtering real speech) and false negatives (processing hallucinated text).
