    Whisper Large-v3-Turbo Hindi LoRA

    Base model: openai/whisper-large-v3-turbo (809 M params) Method: PEFT / LoRA fine-tune → CTranslate2 INT8 deployment Hardware: Single NVIDIA A10G (23 GB) License: Apache-2.0

    GitHub → HuggingFace adapter →

    Overview

    End-to-end ASR fine-tuning pipeline for Hindi: data preparation → LoRA training → CTranslate2 deployment. Trains only 27.9 M parameters (3.33 % of 837 M) on a single A10G in 45 minutes, reducing WER from 35.56 % to 22.25 % on FLEURS hi_in.

    Results

    Model WER (%) Params Trained Inference Engine
    whisper-large-v3-turbo (baseline) 35.56 — HF Transformers
    + LoRA fine-tune (this work) 22.25 27.9 M (3.33 %) HF Transformers
    + CTranslate2 INT8 deployment 22.70 — faster-whisper

    37.4 % relative WER reduction on the FLEURS hi_in test set (n = 418), Whisper-default text normalization. INT8 quantization adds only +0.45 % WER — essentially free for production deployment.

    Pipeline

    Raw audio
    ↓ prepare_data.py        # transcribe + word-level align + segment
Training-ready dataset       # 10–30 s chunks at sentence boundaries
    ↓ train.py               # LoRA fine-tuning (3 epochs, ~45 min)
LoRA adapter (107 MB)
    ↓ convert_and_eval.py    # merge → CTranslate2 INT8 → faster-whisper eval
INT8 model → production inference

    1. Data preparation

    Word-level timestamp alignment from faster-whisper's CTC attention weights, then sentence-boundary segmentation respecting Hindi danda (।) and standard punctuation as split points. Confidence-based filtering removes low-quality segments.

    2. Training

    Single A10G, ~45 min for 3 epochs.

    3. Deployment

    Merge → CTranslate2 INT8 → serve via faster-whisper. The INT8 model loses just 0.45 % WER vs. the BF16 PEFT-merged model.

    Rank (r) 32 LoRA-Whisper (arXiv:2406.06619) — sufficient capacity for ASR adaptation

    Hyperparameter justification (research-backed)

    • r=32, alpha=64, all linear layers (encoder + decoder) — LoRA-Whisper (Yang et al., 2024) found this configuration outperforms decoder-only or q/v-only targeting for ASR.
    • lr=1e-4 with 50-step warmup — conservative for a large pretrained model; warmup prevents early catastrophic forgetting.
    • Effective batch=16 — adapts the Collabora Hindi ASR setup to single-GPU constraints.
    • 3 epochs on ~2K samples — standard for small fine-tuning datasets, with eval every 50 steps to catch overfitting early.

    Inference (PEFT)

    import torch
from transformers import WhisperProcessor, WhisperForConditionalGeneration
from peft import PeftModel

processor = WhisperProcessor.from_pretrained("openai/whisper-large-v3-turbo")
base_model = WhisperForConditionalGeneration.from_pretrained(
    "openai/whisper-large-v3-turbo",
    torch_dtype=torch.bfloat16,
    attn_implementation="sdpa",
)
model = PeftModel.from_pretrained(base_model, "Tachyeon/whisper-large-v3-turbo-hindi-lora")
model = model.to("cuda").eval()

# audio_array: 16kHz float32 numpy array
input_features = processor(
    audio_array, sampling_rate=16000, return_tensors="pt"
).input_features.to("cuda", dtype=torch.bfloat16)

with torch.inference_mode():
    predicted_ids = model.generate(input_features, language="hi", task="transcribe")

print(processor.batch_decode(predicted_ids, skip_special_tokens=True)[0])

    Limitations

    • Data scope — trained on FLEURS read speech (~3.5 h). Performance on conversational, noisy, or code-mixed (Hinglish) audio is not evaluated.
    • Language detection — single-language fine-tuning can degrade Whisper's multilingual auto-detection. Set language="hi" explicitly at inference.
    • Normalization — reported WER uses Whisper-default normalization (which simplifies Devanagari conjuncts). For production Hindi ASR, evaluate with the IndicNLP normalizer; numbers will differ.
